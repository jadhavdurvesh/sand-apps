# SAND Apps

Native application SDK, tooling, examples, and package workflows for SAND OS.

This repository is separate from [`sand-os`](https://github.com/jadhavdurvesh/sand-os). It does not modify the operating-system repository.

**Current target:** SAPP v1, x86-32. See [the compatibility contract](docs/abi-compatibility.md) before building applications.

> SAPP v1 is an early executable container, not yet a stable application ABI. The current kernel exposes only a test syscall; general-purpose console, file, window, and device APIs are not available yet.
