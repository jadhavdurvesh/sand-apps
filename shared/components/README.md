# Component contracts

- **AppShell** — navigation and content viewport.
- **PageHeader** — title, description and primary action.
- **Panel** — grouped content.
- **ActionButton** — primary, secondary and danger variants.
- **StatusPill** — textual state with semantic color.
- **EmptyState** — helpful next action.

The preview implements these as HTML/CSS patterns. This is not yet a native widget toolkit.
